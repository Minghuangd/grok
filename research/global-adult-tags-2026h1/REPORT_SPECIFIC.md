## 4. 按类别看结构

- **装扮恋物**在图站/AI/Pixiv 权重下天然偏高（比基尼/泳装/制服冲前），与视频管站「搜索大词」结构不同——这是多平台综合后的预期结果，不是误差。  
- **行为/完结**（口交、肛交、中出、颜射、手交、乳交、足交…）在管站+AI 侧更稳。  
- **器具/互动**（BDSM、束缚、假阳具、振动棒、女支配）跨平台都有清晰信号。

若你只要「性行为+完结」、不要装扮，可把 CSV 里 `cat!=clothing` 再筛一版。

## 5. 局限（必须读）

1. **X**：无可用的全站 hashtag 公开计数；本层仅低权重先验。  
2. **Pixiv**：官方不提供玩法标签全球榜；衣装侧有 2025–2026 二手整理，玩法侧主要靠 Danbooru 代理。  
3. **Civitai**：`totalItems` API 常为 0，本轮用分页估计；热门 tag 在 800 截断。  
4. **管站**：具体玩法很少进入官方全球搜索 Top10（被 hentai/milf 等大类占位），故用分类/既有洞察作相对分。  
5. 这是 **代理热度综合排序**，不是全网唯一真实 PV 普查。
